fallow — codebase intelligence for TypeScript & JavaScript

A deterministic, Rust-native (oxc) analyzer that answers structural questions about the whole codebase — what's unused, duplicated, circular, complex, or boundary-breaking — and exposes that as CLI text, JSON, an MCP server, and an LSP. No AI inside the analyzer; the findings are reproducible.

Why this wiki exists. fallow is wired into how Claude works in this repo as a better-than-grep tool for codebase intelligence. CLAUDE.md links into these pages with "if X happens → use this". Start at the Decision tree, keep the Reference open, and read This project for the repo-specific setup.

grep / ripgrep vs fallow #

They are complementary. Reach for the right one:

You want…Use
Find a literal string / regex across filesrg (ripgrep) — fallow is not a text matcher
Who imports this symbol? Why is it "used"?fallow dead-code --trace FILE:EXPORT · MCP trace_export
Where is this dependency actually imported?fallow dead-code --trace-dependency PKG · MCP trace_dependency
All import/export edges for a filefallow dead-code --trace-file FILE · MCP trace_file
Is this export / file / dependency dead?fallow dead-code · MCP analyze
Did this change add risk / dupes / boundary breaks?fallow audit · MCP audit / check_changed
Where's the copy-paste?fallow dupes (suffix-array) · MCP find_dupes
Complexity hotspots / refactor targetsfallow health --hotspots --targets · MCP check_health

fallow's own README: it gives agents "structured repo truth instead of forcing them to infer everything from grep."

Install & run #

In this repo fallow is already installed as a dev dependency, so the local binary resolves automatically:

# this project (already set up)
npx fallow --version

# generic install options
npm install --save-dev fallow      # CLI + LSP + MCP + Agent Skill + typed contract
npx fallow dead-code               # run without installing
cargo install fallow-cli           # Rust users (CLI only)

Quick start #

Full sweep

Cleanup + duplication + health for the whole repo.

npx fallow --format json --quiet 2>/dev/null || true

PR / change gate

Only what your change introduced; pass/warn/fail verdict.

npx fallow audit --format json --quiet 2>/dev/null || true

Investigate one symbol

Why is this export flagged? Who consumes it?

npx fallow dead-code --trace lib/api/x.ts:foo \
  --format json --quiet 2>/dev/null || true
Three rules that bite agents. Always append || true (exit 1 = "issues found", not an error — only exit 2 is a real failure). Always use --format json --quiet 2>/dev/null for parsing (never 2>&1). Never run fallow watch (interactive, never exits). Full list: Agent rules.
