MCP tools — fallow-mcp

The fallow-mcp stdio server exposes fallow as 22 structured tools. In this repo it's wired project-scoped (in .mcp.json at the repo root), so it's available to Claude Code here and does not affect fallow/MCP in any other project. These tools are the real "better than grep" surface — they return graph truth, not text.

Project-scoped setup (already done here). Repo-root .mcp.json: 
{
  "mcpServers": {
    "fallow": {
      "command": "npx",
      "args": ["fallow-mcp"],
      "env": { "FALLOW_AGENT_SOURCE": "claude_code" }
    }
  }
}
npx resolves the dev-dependency binary (node_modules/.bin/fallow-mcp). FALLOW_AGENT_SOURCE is attribution only — it never enables telemetry and uploads no code. Reload the MCP servers (or restart the session) for Claude Code to pick it up.
