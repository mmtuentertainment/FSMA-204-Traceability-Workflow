# Directory Structure

> Last updated: 2026-06-04. Reflects the "Batch 58" working state; the source it describes lands on `main` via the phase-3 PR (#12).

A Next.js (App Router) + TypeScript scaffold. Source lives in `app/` (routes + shell) and `lib/` (boundary, API fixtures, DB provider, shared utils); the API contract is in `api/`; planning, ops evidence, and the fallow wiki are kept in dedicated directories.

## Directory Purposes

| Directory | Purpose |
|---|---|
| `api/` | The OpenAPI 3.1 contract (`openapi.yaml`) — single source of truth. |
| `app/` | Next.js App Router: root shell (`layout.tsx`, `page.tsx`) and the route handlers under `app/api/traceability/**`. |
| `app/api/traceability/` | The three live HTTP entry points (two GETs, one PATCH). |
| `lib/api/` | API-facing logic: read boundary, MockRecall source seam + fixture, Problem catalog, exception-review fixtures. |
| `lib/api/generated/` | Generated contract types (`openapi-typescript` output); never hand-edited; fallow-ignored. |
| `lib/db/` | Drizzle schema, lazy Postgres client, and the dormant provider implementation. |
| `lib/db/migrations/` | drizzle-kit-generated SQL migrations + meta snapshots; fallow-ignored. |
| `lib/security/` | Provider-neutral security seams: request context, authorization, idempotency/audit. |
| `lib/shared/` | Cross-cutting utilities shared by `lib/api` and `lib/db` (canonical JSON). |
| `tests/` | Node-runner tests; declared as fallow reachability roots. `tests/db/**` need a Postgres `TEST_DATABASE_URL`. |
| `scripts/` | `.mjs` dev/coverage tooling run via npm scripts (not imported modules). |
| `coverage/provider/` | Committed Istanbul coverage snapshot consumed by `fallow audit` via `FALLOW_COVERAGE`. |
| `ops/deltas/` | Per-batch change evidence (`NNNN-*.md`), the project's change ledger. |
| `docs/fallow/` | Local fallow reference wiki (HTML); documentation only. |
| `.planning/` | GSD planning workspace — state, requirements, roadmap, phases, and the generated `codebase/` map. |
| `.claude/` | Claude Code agent config: the `PreToolUse` fallow commit gate hook, settings, and the `fallow` skill. |
| `.github/workflows/` | CI (Contract Gate). |

## Naming Conventions

- **Route files**: Next.js App Router convention — `route.ts` inside a path-segment folder; dynamic segments are bracketed (`[mockRecallId]`, `[exceptionId]`). The packet route nests the literal segment `packet.csv/`.
- **Source files**: kebab-case `.ts` (`mock-recall-source.ts`, `route-boundary.ts`, `idempotency-audit.ts`); React components are `.tsx` (`layout.tsx`, `page.tsx`).
- **Seam pairs**: an interface plus fixture adapter(s) live in one file; fixture singletons are prefixed `fixture*` (`fixtureMockRecallSource`, `fixtureExceptionReviewRepository`) and `public*` / `noop*` for the defaults (`publicFixtureContextResolver`, `publicFixturePolicy`, `noopAuditSink`).
- **Generated-type aliases**: `type X = components["schemas"]["X"]` mirrors the OpenAPI schema name.
- **Action classes**: dotted lowercase strings in the `Action` union (`mock_recall.read`, `exception.review.update`).
- **DB**: snake_case table/column names in SQL and `pg` row types; camelCase Drizzle column keys mapped to snake_case via `column("name")`. Constraints named `<table>_<purpose>_(check|unique|idx)`.
- **Tests**: `*.test.ts` for type-stripped Node tests, `*.mjs` for plain ESM smoke scripts.
- **Ops deltas**: zero-padded `NNNN-kebab-summary.md`.

## Where to Add New Code

- **New API endpoint** → first add the path + schemas to `api/openapi.yaml`, regenerate types (`npm run api:types`), then create `app/api/traceability/<segment>/route.ts`. Reuse `handleReadAction` for reads; assemble the write seams (auth → policy → idempotency → repo → audit) for mutations.
- **New action class** → extend the `Action` union in `lib/security/authorization.ts` and allow it in the relevant policy (deny-by-default means it is otherwise blocked).
- **New tenant-scoped data source** → define an interface + fixture adapter alongside `lib/api/mock-recall-source.ts`, enforcing a tenant guard that returns `null` on cross-tenant miss.
- **New Problem type** → add to `PROBLEM_CATALOG` in `lib/api/problem.ts` and export a typed constructor.
- **New persistence table / provider work** → add the `pgTable` to `lib/db/schema.ts`, generate a migration with drizzle-kit into `lib/db/migrations/`, and put query logic in a `lib/db/<feature>-provider.ts` (keep it dormant until an approved batch wires it into a route).
- **Shared pure utility** → `lib/shared/` (only if used by more than one layer; import — never copy — to avoid fallow duplication findings).
- **New test** → `tests/` (`*.test.ts` for unit/route, `tests/db/*.test.ts` for Postgres-backed); add the npm script and, if it is a new glob, ensure it matches `.fallowrc.jsonc` `entry`.
- **Batch evidence** → a new `ops/deltas/NNNN-*.md`.
- **UI** → `app/` (currently only the placeholder shell exists; product UI is out of scope per `.planning/STATE.md`).

## Special Directories

- **`lib/api/generated/`** — GENERATED by `openapi-typescript` (`npm run api:types`). Never hand-edit; `npm run api:types:check` (in CI `api:check`) fails if it drifts from `api/openapi.yaml`. Globally ignored by fallow.
- **`lib/db/migrations/`** — GENERATED by drizzle-kit (`*.sql` + `meta/_journal.json` + `meta/NNNN_snapshot.json`). Validated by `npm run db:migrations:check`; applied to a disposable Postgres in the `db-provider-tests` CI job. Globally ignored by fallow.
- **`coverage/provider/`** — committed Istanbul snapshot (`coverage-final.json`) deliberately checked in; fed to `fallow audit` via `FALLOW_COVERAGE` so CRAP scores reflect real coverage. Regenerate with `npm run test:db:coverage`; CI freshness-checks it. See `coverage/provider/README.md`.
- **`.planning/`** — GSD planning state (`STATE.md`, `ROADMAP.md`, `REQUIREMENTS.md`, `PROJECT.md`, `phases/`, `research/`). `.planning/codebase/` holds the generated codebase reference docs (this document's destination).
- **`ops/deltas/`** — the append-only batch change ledger (`0000`–`0058`); each batch's rationale and evidence.
- **`docs/fallow/`** — the local fallow reference wiki (HTML/CSS). Documentation, not analyzable source; fallow-ignored to keep its suppression-syntax examples from registering as findings.
- **`.claude/`** — agent config; `.claude/hooks/fallow-gate.sh` is the `PreToolUse` commit/push gate (blocks on fallow `verdict: fail`), wired in `.claude/settings.json`; `.claude/skills/fallow/` holds the fallow skill.
- **`.mcp.json`** — registers the project-scoped `fallow-mcp` server (structural code-intelligence tools), available only in this repo.
